# NPL Lab08 — Transactions Data Pipeline

## Описание проекта

Полноценный ETL-пайплайн для обработки транзакций с S3, построенный на **Dagster**.

### Что сделано:

- **Ингест данных** из S3 (Parquet + CSV)
- **Очистка и валидация** транзакций
- **Создание витрин**:
  - `fact_hourly_stats` — распределение транзакций по часам
  - `fact_daily_revenue` — выручка по дням (в базовой валюте TGRK)
  - `fact_promo_analysis` — анализ использования промокодов
- **Фильтрация тестовых пользователей** (10% случайно помечены как тестовые)
- **Streamlit-дашборд** с 4 графиками и метриками
- **Scheduled job** (запускается автоматически)

## Как запустить

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Snoopok/npl-lab08
cd npl-lab08
docker compose up -d
```

3. Запустить job в Dagster

Открой Dagster UI: http://localhost:3000
Найди job ingest_s3_data
Нажми Launch Run

4. Открыть дашборд
Streamlit: http://localhost:8501
Что показывает дашборд

Метрики: количество транзакций, выручка, уникальные пользователи, использование промокодов
График 1: Распределение транзакций по часам
График 2: Количество покупок по часам (круговая диаграмма)
График 3: Выручка по дням (линейный график)
График 4: Анализ промокодов (таблица)

Технологии

Dagster — оркестратор
PostgreSQL — хранилище данных
Streamlit — дашборд
Pandas + Plotly — обработка и визуализация
S3 — источник данных

## Почему Dagster + PostgreSQL + Streamlit?

### Обоснование выбора технологий

- **Dagster** — современный оркестратор с отличной типизацией, встроенным UI и простым синтаксисом.
- **PostgreSQL** — надёжное и достаточное хранилище для витрин данных.
 ACID-свойства являются главным фокусом OLTP-баз данных и большим преимуществом Postgres.
- **Streamlit** — позволяет создать красивый интерактивный дашборд за несколько часов без знания frontend-фреймворков.

**Итог:** Это оптимальный стек для демонстрации навыков ETL + Data Engineering в рамках лабораторной работы.
